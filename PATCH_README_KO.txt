PULSE SHIFT v19 · Alt 키 + 로그인/회원가입/게스트

적용:
기존 7곡 Netlify 프로젝트 루트에 압축의 public / netlify / scripts 폴더를 덮어쓰세요.
이전 패치 변경 내용까지 포함한 통합 변경 파일 묶음입니다. 음원/이미지는 기존 파일을 사용합니다.
Netlify Functions와 Blobs를 포함해 Git 연결 또는 Netlify CLI로 전체 프로젝트를 재배포하세요.
정적 파일만 올리는 방식과 단일 HTML에서는 회원가입/로그인이 작동하지 않습니다. 게스트 플레이는 가능합니다.
재배포 후 Ctrl+Shift+R. 기존 로컬 기록/설정은 지우지 마세요.

키 배치:
왼쪽 Alt / 오른쪽 Alt를 각각 L ALT / R ALT로 지정할 수 있습니다.
브라우저가 입력을 전달하는 동안 기본 동작을 막습니다. OS가 선점하는 Alt+Tab 등의 조합은 게임이 차단할 수 없습니다.

계정:
첫 접속 로그인/회원가입/게스트 선택.
아이디: 영문·숫자·_ 3~24자, 대소문자 구분 없음.
비밀번호: 10~128자. 서버에서 salt+scrypt 해시 저장.
세션: Secure/HttpOnly/SameSite=Strict 쿠키, 7일. HTTPS 배포 필요.
회원가입 후 랭킹 닉네임은 별도로 설정합니다. 계정 메뉴에서 로그아웃할 수 있습니다.
서버 오류 시 게스트 선택 가능. 게스트는 온라인 등록 없이 브라우저에 개인 기록 저장.
회원 랭킹은 계정에 연결됩니다. 키 배치/환경설정과 로컬 최고기록은 기기별 저장입니다.
기존 익명 닉네임/랭킹 기록을 새 계정으로 자동 이전하지 않습니다.
이메일 인증/비밀번호 찾기는 아직 지원하지 않습니다.

검증:
계정 생성/중복/로그인/실패/세션 만료/로그아웃/요청 출처/시도 제한/쿠키 속성/랭킹 연결 테스트.
기존 Netlify 랭킹 계약, 배포 구성, 스크립트 문법 검사 통과.
DOM·오디오 모의 환경에서 첫 화면 게스트 진입, 설정, Alt 배치 검증, 112채보 시작/입력/일시정지 검사 통과.
실제 배포된 브라우저에서 로그인과 오디오 재생은 아직 검증하지 못했습니다.
