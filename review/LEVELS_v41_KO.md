# v41 전곡 채보 감수 및 표시 레벨 재산정

160개 검사, 155개 표시 레벨 변경. 채보·음원·기록 ID는 그대로입니다.

최종 채보의 활성 구간 평균 밀도, 2초 지속 밀도, 1초/0.5초 순간 밀도, 동시치기 비율, 200ms 미만 동일 레인 반복 부담, 롱노트 점유시간, 7키 중앙 반복을 반영합니다. 키 수 보정은 (5/키 수)^0.12입니다.

같은 곡/키에서 상위 난이도는 최소 1레벨 높게 표시하며, 난이도별 고정 상한은 제거했습니다. 전체 레벨 범위는 1~30이며 현재 Expert는 16~26입니다.

공식 게임의 레벨과 등가가 아닌 PULSE SHIFT 내부 잠정 척도입니다. 실제 플레이/클리어율 기반 검증 전이며 과장해서 확정 난이도로 보아서는 안 됩니다.

검사: 전체 160개 중복/정렬/레인 충돌/롱노트/편집 경계/밀도 상한/7키 중앙 반복/랭킹 카탈로그, 추출된 원음 이벤트 대조, 런타임과 랭킹 계약.

감수 결과를 근거로 이번 수정은 표기만 변경했습니다. 의도된 고난도 연타와 선율 한쪽 배치를 임의로 삭제하지 않았습니다.
