# v31 채보 감수 결과

기존 채보 비교 기준: v30 전체본의 8곡 × 4/5/6/8키 × 4난이도, 총 128채보.
음원 편집·재킷·폰트·게임 판정은 유지하고 채보의 배치와 반주 밀도를 검토했습니다.

## 확인한 문제

1. v30의 밀도 제한은 반주를 추가하는 시점의 주변 노트만 확인했습니다. 나중에 추가되는 반주까지 포함한 최종 채보에서는 제한을 넘을 수 있었습니다.
2. 일정 박자마다 프레이즈를 새로 계산하면서 같은 음이 불필요하게 다른 레인으로 이동하거나, 프레이즈 경계에서 음높이 진행과 레인 방향이 반대가 되는 경우가 있었습니다.
3. 선율을 따르는 한손 구간에 반주까지 겹치면서 부담이 커지는 사례가 있었습니다.

## 수정

- 과밀 구간에서 분석상 강도가 낮은 반주를 우선 제거. 멜로디의 시각·피치·길이는 하나도 삭제/변경하지 않았습니다.
- 모든 노트 시작점에서 실제 0.5초/1초 이동 구간을 검사. 완성된 채보를 대상으로 밀도 제한을 보장합니다.
- 겹침과 과도한 연타를 만들지 않는 범위에서 반복음 레인과 선율 방향을 수정했습니다.
- 국소적으로 손 부담이 큰 경우 반주를 반대손의 여유 있는 레인으로 옮겼습니다. 전체 좌우를 강제로 50:50으로 맞추지 않았습니다.

| 지표 | v30 | v31 |
|---|---:|---:|
| 전체 노트 수 | 109,456 | 106,834 |
| 멜로디 노트 수 | 65242 | 65242 |
| 음높이/레인 방향 충돌* | 151 | 26 |
| 180~600ms 반복음의 레인 변경 | 671 | 267 |
| 한손 85% 이상 집중 구간** | 257 | 234 |

* 600ms 이내, 한 옥타브 이내 연결. 믹스 음원에서 추정한 피치에 대한 지표이며 실제 악보 정답률은 아닙니다.
** 1초 간격으로 조사한 2초 창, 중앙키 제외 8노트 이상. 겹치는 창이 있어 독립된 234개 패턴을 의미하지 않습니다.

## 남은 한계

- 음높이는 보컬/악기가 섞인 음원에서 추정했습니다. 실제 주선율 대신 반주나 배음이 잡혔는지는 이 구조 검사만으로 확정할 수 없습니다.
- 남은 방향 충돌 26곳, 한손 집중 구간은 기록에 남겼습니다. 음계를 더 강제하면 겹침이나 손 부담이 생기는 경우까지 일괄 수정하지 않았습니다.
- 실제 타건·청음·전곡 수동 완주 감수는 하지 않았습니다. 이번 작업은 데이터와 음원 분석에 근거한 구조 감수이며 상용게임의 수동 채보 검수를 대체하지 않습니다.
- 싱크는 변경하지 않았습니다. 피치, 주선율 선택, 가사 연결의 청음 확인이 다음 검수 과제입니다.

## 검증

- 모든 멜로디 시간·피치·롱노트 길이가 v30과 일치.
- 레인 겹침/중복 없음, 롱노트 편집 연결부 통과 없음, 유지 중 전 레인 점유 없음.
- 160채보의 실행·그리기·입력·일시정지 및 랭킹 총점 일치 검사.
- 변경한 채보만 새 ID 부여하여 이전 점수와 분리.

세부 데이터: chart-review-before.json / chart-review.json / chart-changes.json.

## 7KEY 추가 및 최종 전체 검사

기존 128채보 외에 7KEY 32채보를 추가하여 최종 160채보를 검사했습니다. 7KEY는 편집 음원의 이벤트에서 별도 생성했으며, 8KEY 레인을 하나 지운 채보가 아닙니다.
7KEY 생성 후 과밀 반주 907개를 줄이고 선율 방향 충돌을 40→5곳으로 줄였습니다. 중앙 Space 반복 간격은 Easy 260 / Normal 230 / Hard 200 / Expert 180ms를 기준으로 검증했습니다(반올림 허용 1.5ms).
Neon Eclipse 7KEY Expert 30.301초 선율을 중앙에서 오른손 레인으로 이동해 160ms 엄지 반복을 제거했습니다.

최종 160채보의 레인 범위·중복·겹침·롱노트 연결부·최종 0.5/1초 밀도 제한·카탈로그 총점이 통과했습니다. 16개 오디오도 전체 디코딩을 통과했습니다.
5KEY 보조키 교대/롱노트 공유/키 충돌/설정 저장, Tab 전환, 7KEY 별도 랭킹 제출, 전 키 모드의 3종 노트 스킨 자동 테스트를 통과했습니다. 브라우저에서 7KEY 선택 화면과 노트 설정을 확인했습니다.

위 비교표는 기존 128채보에만 해당합니다. chart-review.json은 최종 160채보, chart-changes-7key.json은 신규 7KEY 감수 내역입니다. 사람의 청음·전곡 수동 완주 감수는 완료하지 않았습니다.
