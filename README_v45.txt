PULSE SHIFT v45 — 프레임 설정
v44가 적용된 프로젝트 루트에 같은 경로로 덮어쓰세요.
신규 public/frame-pacing.js도 반드시 추가해야 합니다.

설정 > 화면과 노트 > 프레임 설정
- 무제한(기본) / 60 / 120 / 144 / 165 / 240 FPS
- 현재 FPS 표시 켜기/끄기 (기본 끄기), 플레이 상단 표시
- 설정 자동 저장

프레임 제한은 캔버스/표시 갱신에만 적용됩니다.
건너뛴 렌더링 프레임에도 기존 requestAnimationFrame의 게임 판정과 키음 예약은 실행됩니다.
키보드 입력은 이벤트 시각 기반 기존 판정을 유지합니다.
FPS는 실제 게임 그리기 빈도를 약 0.5초 단위로 계산합니다.
모니터/브라우저 주사율 이상으로 화면 갱신을 강제하지 않습니다.
서로 배수가 아닌 제한과 주사율 조합에서는 프레임 간격이 불균일할 수 있습니다.

검증: 빌드, 기존 160채보 모의 실행/입력 회귀, 재생/로딩 회귀,
30가지 주사율/제한 조합 및 설정 저장 검사 통과.
실기기 FPS나 GPU 성능 측정은 포함하지 않습니다.
